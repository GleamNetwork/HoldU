# 原型与硬件说明

## 打开方式

下载仓库或解压整理包，双击 [同频三端离线原型](../../prototypes/tongpin-demo.html)。内含小频图像和样式，可离线看演示。用户端、志愿者端、管理端均为虚构流程。

[在线 Demo](https://tongpin-b2-companion.ruomengbi.chatgpt.site/) 是既有版本；本轮未更新发布。此链接与仓库上传是两件事。

## 能力边界

当前演示使用固定脚本、虚构健康数据与模拟分配，不是实际问诊服务、持续值守、真实医疗转诊或已验证的风险识别。V0.4 Profile 和规则仅在文档，未自动写入此 HTML。

志愿者排班、日接待上限、同时接待、休息、自检及交接是可演示流程。示例容量与时段是产品演示配置，不是国际规范。管理端普通管理员与专业督导的证据权限应分开。

## 手表和插件

当前步数、心率、睡眠主要为模拟数据。已有 Web Bluetooth 心率方向的实验代码不等于真实设备联调完成；普通蓝牙心率服务并不同时提供所有厂商的步数和睡眠。独立 HTML 不承诺蓝牙兼容。

HealthKit、Health Connect / Wear OS、华为等接入均需要各平台权限、适用客户端、厂商接口及真实设备测试。设备来源、时区、单位、佩戴质量、缺失状态必须入证据链；医疗意义另由适用设备与专业标准确认。
