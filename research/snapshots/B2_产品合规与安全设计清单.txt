# B2 产品合规与安全设计清单

## 角色与责任

- [ ] 页面显著说明：本产品不提供诊断，不替代心理热线、专业人员或急救服务。
- [ ] AI 输出只作为提示；危机确认、升级和信息披露由受训人员负责。
- [ ] 志愿者有准入培训、能力边界、督导、暂停与退出机制。
- [ ] 明确平台、志愿者、专业机构和应急部门各自责任。

## 检测与模型

- [ ] 输出“需关注信号 + 依据 + 不确定性”，不输出医学诊断。
- [ ] 不把单一关键词、情绪分数或量表当作未来自杀预测。
- [ ] “低风险”不会自动结束支持；允许人工覆盖与用户主动升级。
- [ ] 对隐语、反讽、方言、少数群体、残障表达和噪声语音做漏报/误报测试。
- [ ] 记录模型/规则版本、阈值、触发原因和人工处置结果。

## 数据与隐私

- [ ] 默认端侧处理；上传云端需有明确目的和必要性。
- [ ] 健康、语音、聊天、位置、联系人按敏感个人信息管理。
- [ ] 分项说明收集目的、保存期限、访问者、撤回和删除方式。
- [ ] 非必要不收真实姓名、精确位置、通讯录和完整原始对话。
- [ ] 紧急披露采用预先告知、人工确认、最小范围和完整审计。
- [ ] 演示只用合成数据；数据集不含可识别的真实危机个案。

## 危机工作流

- [ ] 资源库按地区、时间、年龄和服务类型版本化，标明最后核验日期。
- [ ] 中国区至少配置 12356；按情形配置 120、110 等升级路径。
- [ ] 设计“无人接单、掉线、热线占线、定位未知、用户拒绝”等失败回退。
- [ ] 支持安全计划、交接、随访和事件复盘，而非只做一次聊天。
- [ ] 高风险对话期间减少无关提问，不要求用户重复叙述。

## 志愿者保护

- [ ] 接单上限、夜班限制、强制冷却和高危事件自动卸载。
- [ ] 可一键请求督导或转交专业人员。
- [ ] 事后去标识化复盘、心理支持和异常暴露监测。
- [ ] 绩效不以“留住用户”或“处理更多高危单”为导向。

## 证据与答辩

- [ ] 把主要指标拆成：可及性、接通时间、人工覆盖率、转介完成率、误报/漏报、用户体验、志愿者负荷和安全事件。
- [ ] 不用“成功阻止自杀”作为短期黑客松可验证结论。
- [ ] 每项流程规则都有官方来源、版本和适用地区。
- [ ] 明确哪些结论来自指南，哪些只是待验证的产品假设。

## 上海落地补充

- [ ] 上海区号/定位命中时，将 12356 与 962525 识别为并轨的上海市心理热线节点。
- [ ] 展示7×24小时、市—区接听网络和跨区溢出路由，但不声称已完成真实政府接口。
- [ ] 志愿者画像包含资质审核、岗前培训、理论/实践考核、督导和可处理范围。
- [ ] 青少年场景配置 12355 与 12356/962525 的双向转介，并实行最小信息披露。
- [ ] 为未成年人、老年人、残障用户及无法使用智能终端者提供电话、人工和无障碍替代路径。
- [ ] 若进入互联网诊疗，执行上海互联网医院准入、医师实名、知情同意、记录保存、境内存储和监管接入要求。
