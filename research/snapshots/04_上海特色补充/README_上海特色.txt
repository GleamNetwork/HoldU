# B2 上海特色补充：从“聊天工具”到超大城市心理急救网络

更新日期：2026-09-06

## 1. 上海最值得写进方案的五个特色

### 1. 12356 与 962525 并轨，而非另起一套热线

自2025年1月起，上海市心理热线接入全国统一心理援助热线 12356，与原 962525 并轨，保持全年无休、7×24 小时服务。产品中可以把两者配置为同一个上海专业接入节点，避免重复派单。

官方依据：

- `01_上海市心理热线962525建设工作方案_2023.pdf`
- `06_上海12356与962525及12355协同_2026.html`
- [12356上海市心理热线服务指南](https://www.smhc.org.cn/ggjsws1/xlrx/xlrxfwzn.htm)

### 2. 市—区分布式接听网络，天然适合“去中心化急救网”叙事

上海方案不是单一中心坐席，而是由市、区精神卫生中心共同组成接听网络，统一短号、标准化工作室、统一处置流程和市级管理。这与 B2“去中心化心理急救网”高度一致。

原型可设计：上海总路由节点 + 各区接听节点 + 专业机构节点 + 12355/120/110 外部节点，并展示占线溢出、跨区派单和回退机制。

### 3. 志愿者不是“任何热心网友”，而是准专业化队伍

《962525建设工作方案》要求相关教育背景/资格、资质审核、岗前理论和实践考核、培训合格后方可接线，并建立持续培训和督导。各接听点至少每月组织一次团体或个体督导，市级至少每季度组织一次全市督导。

因此产品里的志愿者画像应至少包含：资格状态、培训模块、考核、督导参与、当前负荷、可处理范围和暂停状态。AI 匹配不能只依据兴趣或在线状态。

### 4. 上海已有青少年跨热线双向转介

上海 12356/962525 与团市委 12355 青少年服务热线开展协同：心理热线遇到青少年法律、权益等问题可转至 12355；12355 识别心理危机时可转接心理热线。B2 可以把它做成“情绪支持—权益援助—专业危机干预”的多机构工作流。

产品要注意：跨机构转介不是把全部聊天记录直接共享，而应基于同意、必要性和最小披露生成结构化交接摘要。

### 5. 上海强调人机协同、特殊群体替代方案和强监管

《上海市促进人工智能产业发展条例》支持人机协同的智能医疗系统，同时要求智能公共服务考虑老年人、残疾人、妇女、未成年人等群体并设置必要替代方案。

若产品进入互联网诊疗或与互联网医院共建，《上海市互联网医院管理办法》进一步要求：AI 不得冒用、替代医师提供诊疗；相关系统和医疗 AI 接受监管；医师实名接诊；充分告知并取得知情同意；诊疗过程记录、医疗数据安全和境内存储均有要求。

## 2. 推荐的“上海版”Demo 架构

`端侧关注信号 → 用户确认求助 → 上海市级派单路由 → 区级合格接听员 → AI Copilot → 12356/962525专业升级 → 12355青少年权益协同 / 120医疗急救 / 110公共安全 → 区域资源转介 → 回访与督导`

建议在演示地图上显示：

- 上海市级路由中心及16区服务节点（仅作概念演示，真实接入需授权）。
- 12356/962525 当前状态和预计等待时间。
- 青少年场景的 12355 双向转介。
- 各区精神卫生中心、社区心理服务点或“心灵地图”资源。
- 志愿者容量、冷却状态和督导可用性。
- 无人接单、掉线、热线占线、用户拒绝披露位置等回退流程。

## 3. 上海版产品红线

- 不能把未经培训的普通志愿者包装成 962525/12356 接听员。
- 不能声称已经与政府热线、精神卫生中心或 12355 建立真实接口，除非取得书面授权。
- 不能让 AI 代替医师或专业接听员作出诊断、治疗和危机强制处置决定。
- 不能因“智慧城市/公益”名义默认收集位置、通讯录、语音和完整聊天记录。
- 跨热线、跨区或跨机构转介时，必须设置知情说明、人工确认和最小披露。
- 若进入互联网医院体系，医疗信息不得存放在境外服务器，并应接受上海互联网诊疗监管要求；普通非诊疗陪伴产品不应误称互联网医院。
