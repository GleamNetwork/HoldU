# 同频 UI 基调

这份文件是同频后续界面设计的色彩与语气锚点。新增页面或组件应优先复用这些 token，不随意引入高饱和新色。

## 设计方向

柔光花园。它不是糖果色治愈产品，也不是冷色医疗仪表盘。整体要温暖、安静、可信，给处在压力或低落状态中的人留出呼吸空间。

平台感：iOS 原生感的移动端体验，圆角克制、层级清晰、触控目标充足。页面优先展示一个明确动作，不把风险信息做成醒目的分数或诊断。

## 色彩 token

| Token | 色值 | 使用语义 |
| --- | --- | --- |
| `canvas` | `#FFF8F5` | 页面底色，带一点柔粉的白 |
| `surface` | `#FFFCFA` | 信息表面与底部导航 |
| `ink` | `#493B3F` | 主文字与高对比图标 |
| `muted` | `#796B70` | 次要文字 |
| `petal` | `#F3C7C3` | 陪伴、小频、需要被接住的时刻 |
| `apricot` | `#E7AE7B` | 主操作与连接行为 |
| `butter` | `#F1DDA1` | 安抚、练习和低压力提示 |
| `lilac` | `#D9CBE1` | 隐私、授权、安静的设置页 |
| `sage` | `#C7D6C3` | 设备摘要、恢复与长期状态 |
| `line` | `#E9DEDA` | 柔和分隔线 |

使用规则：一个功能区只以 1 到 2 个彩色材质为主。彩色负责区分语义，不把所有颜色同时放进一个按钮或单张卡片。主按钮使用 `apricot` 加深色文字，禁止霓虹光晕与高饱和渐变。

## 组件规则

- 页面背景以 `canvas` 为主，彩色只作为局部的雾化材质或图标底色。
- 卡片半径为 24px，底部抽屉为 30px，胶囊只用于短操作按钮或标签。
- 阴影是带暖灰色调的浅阴影，不使用纯黑投影。
- 动效只服务于页面切换、底部抽屉和按压反馈，并需尊重减少动态效果设置。
- 所有风险相关内容用平静、明确的语言呈现，不制造恐慌，也不承诺诊断或医疗效果。

## 小频

小频是柔软、在场而不替用户做决定的陪伴角色。视觉上保留白色小兔、暖色耳机与一点杏橙或粉色点缀；避免幼态化、夸张表情和过度卖萌。文案使用短句，例如“我在”“先不用解释”“你可以自己决定要分享什么”。

首页把小频作为唯一主视觉，不把它缩成图标或 CSS 图形。资产有两种状态：安静闭眼和温柔挥手。动效只使用缓慢呼吸、轻微漂浮、柔和心跳，以及用户点按主按钮后的状态切换。动效必须尊重系统的“减少动态效果”设置。

## 首页构图锁定

- 页面本身适配 iPhone 纵向安全区，不展示模拟手机外壳。
- 背景是低对比的晨光房间。小频停在画面上半部，文字与 CTA 落在下半部的雾化留白中。
- 首页只保留一个主操作“和小频聊聊”。底部使用三项原生感导航：陪伴、记录、我的。
- CTA 使用杏橙材质，深色文字，底部导航使用半透明乳白材质。不要在首页重新引入多张功能卡片。
- 添加到 iPhone 主屏幕后以 PWA 独立窗口打开。必须保留 manifest、Apple touch icon 与离线缓存配置。

## 内容边界

- 设备感知只可写成“本地摘要”或“你选择分享的变化”，不能写成临床结论。
- AI 是倾听提示与连接辅助，不替代专业判断。
- 遇到即时危险，界面应引导用户联系当地紧急服务或可信任的人，并保留人工接管路径。
